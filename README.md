# Build-A-Bowl

## Project Brief

Build-A-Bowl is a fictional restaurant website created to give customers a simple and interactive way to explore food options and create their own bowl. Customers can view the menu, learn about the restaurant, build a bowl by choosing different ingredients, and contact the restaurant.

## Technologies Used

* HTML5
* CSS3
* Git
* GitHub
* GitHub Pages

## Setup Instructions

1. Clone or download the repository.
2. Open the project folder in Visual Studio Code.
3. Open `index.html` using Live Server or a web browser.

## Business Rationale

The website is designed around the idea of giving customers control over their meal. Instead of choosing only from fixed meals, customers can select their own base, protein, vegetables, sauce, and toppings. The website also provides a menu for customers who prefer ready-made combinations and a contact page for questions, orders, and feedback.

## Website Pages

* **Home Page:** Introduces Build-A-Bowl and its concept.
* **About:** Explains the restaurant's story and values.
* **Menu:** Shows signature bowl combinations.
* **Build Your Bowl:** Allows customers to customise their bowl.
* **Contact:** Provides a form for customers to get in touch.

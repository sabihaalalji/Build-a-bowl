# BUILD-A-BOWL 🍜

## Project Brief

BUILD-A-BOWL is a restaurant landing page where customers can explore signature bowls and create their own meal by choosing their preferred base, protein, toppings, and sauce.

## Technologies Used

* HTML5
* Git
* GitHub

## Setup

Clone the repository and open `index.html` in a web browser.

## Screenshots

Screenshots of the completed website will be added here.

## Business Rationale

BUILD-A-BOWL gives customers more control over their meals by allowing them to create combinations based on their own preferences. The website makes this concept simple to understand while providing a professional online presence for the restaurant.
